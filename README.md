# 💳 Credit Card Default Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on predicting whether a credit card customer will default on their next month's payment using Machine Learning techniques.

The project uses customer information, credit limits, repayment status, bill amounts, and payment history to predict the likelihood of payment default.

## 🎯 Objectives
- Analyze credit card customer data.
- Perform data cleaning and preprocessing.
- Identify and handle outliers.
- Visualize relationships using a correlation heatmap.
- Build Machine Learning classification models.
- Evaluate model performance.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## ⚙️ Project Workflow
1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Cleaning
4. Outlier Detection and Treatment
5. Correlation Heatmap
6. Train-Test Splitting
7. Feature Scaling
8. Logistic Regression
9. Model Evaluation

## 🤖 Machine Learning Algorithm
- Logistic Regression

## 📊 Dataset Features
The dataset includes:
- Customer ID
- Credit Limit
- Age
- Education
- Marriage Status
- Repayment Status
- Bill Amounts
- Payment Amounts
- Default Payment Status

## 🚀 Expected Outcome
The model aims to classify customers into two categories:
- 0 – No payment default
- 1 – Payment default

## 📚 Learning Outcome
This project helps develop practical knowledge of data preprocessing, data visualization, classification algorithms, and Machine Learning model development.
